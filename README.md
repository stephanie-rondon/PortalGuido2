# PortalGuido
O projeto tem como principal função o acesso dos alunos aos conteúdos de forma simples. Os professores também tem acesso, de forma administrativa, postando os conteúdos.
# O que soluciona?
Ele auxilia na consulta de matérias de qualquer ano da escola, independente de qual ano o usuário esteja. Facilitando o aprendizado perdido.
